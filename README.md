# Lexifyd - Context-Aware Tamil Lexical Engine

A full-stack application for learning Tamil polysemy using Gemini AI.

## Deployment

This app is designed to run on Hugging Face Spaces using Docker.

### Configuration

Ensure you set the following secret in your Space settings:
- `GEMINI_API_KEY`: Your Google Gemini API Key.
